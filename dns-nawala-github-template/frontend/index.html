Apa itu DNS Nawala?

DNS Nawala adalah layanan penyaringan internet yang digunakan di ISP, sekolah, kantor, dan institusi lain untuk membantu memblokir akses ke konten berbahaya.

Cara Pakai

  1. Masukkan DNS pada perangkat, router, atau jaringan.
  2. Simpan pengaturan.
  3. Gunakan internet seperti biasa, situs berbahaya akan diblokir.
